CBTF Practice Quiz: Contents

- 6 questions, in a random order
	- Agreements and understanding question
		- Read through, click that you understand
	- Multiple choice, true/false questions
		- True/false, multiple choice select one, multiple choice select many
	- Symbolic input questions
		- Entering formulas such as "O(f(n))" or "E=m*c^2"
	- Proof blocks question
		- Given a series of steps for a proof (or algorithm) including incorrect steps, assemble the correct ones in the correct order
	- Array fill-in
		- Given a 1-D or 2-D array, fill in the correct values
	- Comments
		- List any comments you have (but must put something, at least "none", for credit)
